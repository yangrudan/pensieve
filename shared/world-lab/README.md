# 可跨机器查看的 World 实验

这里是五组 AI 大厅实验的只读资源。包含 122 张生成/合成输入图、五份 SPZ、两张全景、原始输入参数及已完成任务的公开元数据。没有个人记忆照片、API Key、供应商签名下载地址、私人地点标签或运行状态文件。

Mac mini 在仓库目录执行 `git pull --ff-only`，然后重启原 Python 服务，访问 http://localhost:4174/atlas/lab/ 即可。使用 `server.py` 提供页面和资源；仅启动静态文件服务不能提供实验接口。不需要复制或覆盖 `.runtime/state.json`，也不需要重新生成。

服务端将本机实验记录与本目录记录合并展示：同 ID 或同 case 的本机记录优先，模型文件也优先使用本机文件。没有本机输入集时从这里读取输入；没有本机模型文件时从这里读取已有模型。共享记录只用于展示和已完成任务复用，不写入本机记忆、地点或额度计数。用户在 Mac mini 新生成的记忆继续存放在其 `.runtime/`。

`index.json` 不是完整的服务端状态，不能拿它替换 `state.json`。`checksums.json` 记录发布时输入、模型和索引文件的 SHA-256，可检查传输完整性。Git 同步的是已发布的实验，个人记忆不在不同机器间自动同步；各设备原有额度计数也不被覆盖或相加。

实验质量评审仍见 `WORLD_EXPERIMENTS.md`：可以查看模型不代表四组世界都已通过视觉质量验收。资源齐全后若特定浏览器仍无法渲染，请比较 Chrome 和 Safari 的具体报错；本资源包不保证所有 GPU/浏览器兼容。

第五组为 2026-10-27 的 72 视角重建存档：结构初检通过，细节尚未优化到位。`reviews/stone-hall-multiview-v3/` 保留总览与检查记录；它不是最终高细节版本。输入附带几何检查和相机文件，供复现与验证。
